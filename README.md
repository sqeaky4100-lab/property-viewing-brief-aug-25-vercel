# property-viewing-brief-aug-25-vercel

A property listing and viewing application built with **Next.js 16** and **Tailwind CSS**, ready for deployment on **Vercel**.

## Features

- 📋 **Listings page** — browse all properties with key details (price, beds, baths, sqft)
- 🏠 **Detail page** — view full property information, features list, and "Book a Viewing" CTA
- 📸 Photo thumbnails via Unsplash
- ✅ Statically generated at build time (`generateStaticParams`)
- 🚀 Zero-config Vercel deployment

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Push this repository to GitHub, then import it in [Vercel](https://vercel.com/new). No extra configuration is needed.
